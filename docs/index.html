Review De-duplication & Trust Clustering

A working miniature of Gangnam Beauty Guide's review-syndication pipeline: reviews ingested from multiple Korean sources, duplicate candidates detected with cheap language-agnostic math, ambiguous cases resolved by an LLM judge — and every duplicate flagged, never deleted, because the duplication pattern is itself a trust signal. The live site already translates single-source (GangnamUnni) reviews into English summaries; this is the stage that unlocks multi-source syndication — and it must run on source-language originals before summarization, which destroys the textual evidence dedup relies on.

Fixture data. All 20 reviews, clinics, doctors and handles below are fictional, modeled on real Korean source formats (Naver cafes, blogs, clinic testimonials). No real clinic is named — you can't demo "suspected seeding" labels on real businesses. Code & pipeline: github.com/SHRony/gbg-review-dedup

1Normalize + block

Prices folded (35만원 ≡ ₩350,000), punctuation stripped. Candidates nominated by char-bigram similarity (language-agnostic — no Korean tokenizer needed), metadata (same procedure + price + date window), and fuzzy author-handle match.

2Cluster (cheap math)

Union-find over pairs above the threshold you pick below. Near-exact copies auto-merge; clearly distinct pairs auto-reject; nobody pays an LLM for the obvious cases.

3LLM judge (uncertain band only)

Only ambiguous pairs — 4 of 190 here — get a structured verdict with rationale. It also catches what n-grams structurally can't: the same review posted in Korean and English.

The threshold is a product policy, not an implementation detail — it sets how aggressively you accuse reviewers of being shills. Drag it low and watch genuine reviews get wrongly merged; toggle the judge to see stage 2 rescue them and catch the cross-language duplicate.
